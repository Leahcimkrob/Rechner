# Rechner

A simple calculator application created as my first task during my internship as part of my retraining to become an IT Specialist for Application Development.

## About the Project

The goal of this project was to create a basic calculator and gain practical experience in software development.

The calculator supports basic arithmetic operations:

* Addition
* Subtraction
* Multiplication
* Division

The project was developed as an exercise to become familiar with the development environment, programming concepts, and structured problem solving.

## What I Learned

During this project, I gained practical experience with:

* Basic programming concepts
* Working with variables and methods
* Handling user input
* Implementing arithmetic operations
* Error handling
* Debugging and testing
* Using Git and GitHub
